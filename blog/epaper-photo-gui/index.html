EPaper Image Generator GUI

Build a Qt workflow for preparing photos and sending them to a Raspberry Pi e-paper display over SSH.

Ahmad RoshanfarOctober 22, 2025· 2 min read·Updated Oct 20, 2026
On this page

Back to top ↑

EPaper Photo prepares an image on your desktop and sends it to a Raspberry Pi e-paper display. The Qt interface shows the original and processed image side by side, so you can adjust the result before refreshing the panel.

How it works#

  • UiController connects the QML controls to image processing and transfer.
  • ImageProcessor maps the photograph to six colors and spreads quantization error into neighboring pixels. This dithering preserves the impression of shades the panel cannot display directly.
  • Connectivity uploads the result with SCP, then starts the Raspberry Pi display program over SSH.
  • RPi-EPaper drives the physical panel over SPI.

Image preparation stays on the desktop; the Pi receives the prepared file and handles the display.

Run it#

Install CMake, a C++ compiler, and Qt 6.8 or newer with Quick and Concurrent:

bash
git clone https://github.com/AhmadRoshanfar/EPaper-Photo.git
cd EPaper-Photo
cmake -S EPaper-Qt -B build \
  -DCMAKE_PREFIX_PATH=/path/to/Qt/gcc_64
cmake --build build
./build/appEPaper_Qt

For the hardware path, enable SPI on the Pi, install its C/C++ build tools, and copy the display program from the checkout:

bash
ssh-copy-id user@board
scp -r RPi-EPaper user@board:~/
ssh user@board 'sudo raspi-config nonint do_spi 0'

Wire the supported panel according to its driver documentation. The current transfer code expects ~/RPi-EPaper, rebuilds the driver there, and runs ./epd; the remote account needs the corresponding build and hardware permissions.

Open a photo, adjust the conversion, enter the Pi connection details, and send the processed image. The local preview is also useful without a connected display.

Where it fits#

Use it for desktop photo preparation, checking how images survive a restricted palette, and updating a network-connected photo frame.
